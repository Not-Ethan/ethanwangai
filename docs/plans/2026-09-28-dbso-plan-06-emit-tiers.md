### Task 5.2: Hero SVG under the canvas, og image, and the no-WebGL tier

**Files:** `src/fallback/StaticPlates.tsx`, `src/fallback/glSupport.ts`, `src/app/opengraph-image.tsx`, modify `src/gl/Scene.tsx`, `src/site/Site.tsx`, `src/site/sections/Yours.tsx`

**Interfaces:**
- `glSupport.ts`: `export function webgl2Available(): boolean` (creates a probe canvas, checks `getContext('webgl2')` and `ANGLE_instanced_arrays`-equivalent by `gl.getParameter(gl.MAX_VERTEX_ATTRIBS) >= 16`; returns false if `location.search` contains `nogl=1`).
- `<StaticPlates mode="hero" | "tier" />`: `hero` renders the inline landscape or portrait hero SVG (by `matchMedia('(orientation: portrait)')`) in a `position: fixed; inset: 0; z-index: 0` layer, scaled in x by `HERO_ASPECT / currentAspect` via a CSS variable updated on resize, colors from CSS variables; `tier` additionally fetches `/plates/<machine>.svg` lazily (on first need) and shows the plate for the active section (from `useScroll` in a rAF, class toggles only), fades each in over 300 ms, animates ~24 `rect[data-hot]` per plate with a CSS keyframe (`@keyframes hotTick { 0%,80% { fill: var(--ink) } 85%,100% { fill: var(--hot) } }`, 1.6 s, staggered by `nth-child`, paused under reduced motion), and on the visitor form's submit appends `<rect>` bars = words and rails = sentences into the slot area of the `yours` plate in plain DOM.
- `Scene.tsx`: renders `<StaticPlates mode="hero" />` beneath the canvas always; if `!webgl2Available()` or the error boundary catches, or `webglcontextlost` fires after T0 (Review Focus #5), it unmounts the Canvas and switches `StaticPlates` to `mode="tier"`; the DOM remains untouched.
- `opengraph-image.tsx`: `export const runtime = 'nodejs'`, size 1200 × 630, `ImageResponse` with paper background `#F1EEE9`, the headline in Archivo 700 at 64 px top-left (loaded from `node_modules/@fontsource/archivo/files/archivo-latin-700-normal.woff` via `fs.readFile`), the deck in 22 px, and an inline `<svg>` of `POSTER_RECTS` at the lower right.
